IMAGE NAMING CONVENTION
=======================
Drop your images in this folder and name them exactly as listed below.
The frontend components reference these paths as /images/<filename>.

HERO / BANNER
-------------
hero-bg.jpg          — Full-width hero background (1920×1080 recommended)
hero-overlay.png     — Optional dark overlay / texture if needed

ABOUT SECTION
-------------
about-students.jpg   — Photo of students in class or playground
about-building.jpg   — School building exterior or main gate

ACADEMICS SECTION
-----------------
academics-nursery.jpg  — Nursery/KG classroom or activity photo
academics-primary.jpg  — Primary school (Class 1–5) photo
academics-middle.jpg   — Middle school (Class 6–8) photo
academics-senior.jpg   — Senior school (Class 9–10) photo

GALLERY (optional, up to 6 images)
-----------------------------------
gallery-1.jpg through gallery-6.jpg

LOGOS / BRAND
-------------
logo.png             — School logo (transparent PNG, ~200×80)
logo-white.png       — White version of logo for dark backgrounds (footer/nav)

TESTIMONIALS
------------
testimonial-1.jpg    — Parent/student headshot (square, ~200×200)
testimonial-2.jpg
testimonial-3.jpg

FORMATS: JPG or PNG. Keep file sizes reasonable (hero < 800 KB, others < 300 KB).
